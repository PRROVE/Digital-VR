# Releases

이 폴더는 Digital-VR의 배포용 Windows 빌드를 버전별로 보관합니다.

## Windows 패키지

| 버전 | 경로 | 상태 |
| --- | --- | --- |
| ver1 | `Windows/ver1/DigitalVR2-Windows.zip` | 보관 |
| ver2 | `Windows/ver2/DigitalVR2-Windows.zip` | 보관 |
| ver3 | `Windows/ver3/DigitalVR2-Windows.zip` | 보관 |
| ver4 | `Windows/ver4/DigitalVR2-Windows.zip` | 현재 |

각 ZIP은 독립 실행형 Windows 빌드입니다. 압축을 푼 뒤 `DigitalVR2.exe`를 실행합니다.

## 추가 규칙

1. 새 빌드는 `Windows/verN/` 폴더를 만들고 `DigitalVR2-Windows.zip` 이름으로 추가합니다.
2. 기존 버전 ZIP은 덮어쓰거나 삭제하지 않습니다.
3. 새 최신 버전은 이 표의 상태를 `현재`로 바꾸고 이전 버전은 `보관`으로 표시합니다.
4. 대용량 ZIP은 저장소 이력 증가를 줄이기 위해 GitHub Releases 배포 자산 사용을 권장합니다.
